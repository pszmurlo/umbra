# Umbra

An interactive solar eclipse, seen through smoked obsidian.

**Live:** [pszmurlo.github.io/umbra](https://pszmurlo.github.io/umbra/)

The photosphere is a ruinous glare. Lower the plate to watch the crescent form. In totality the plate lifts by itself, and the corona — kintsugi in a black sky — is the only light left.

## Run

```bash
npm install
npm run dev
```

## Look

- Drag the sky to move the moon
- Scroll to lean in
- Space to play and pause
- Lunar distance chooses total or annular
- Path offset slides you off the centerline, into a mere partial
